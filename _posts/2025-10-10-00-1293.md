[web/小游戏平台远程资源更新](https://forum.cocos.org/t/topic/155155/20)
```
包打出来之后src目录下有个setting.json,这个文件类似于cocos下载的manifest文件,
通过这个文件解析后指向远程包的地址进而下载到远程包的文件,将这个改成支持远程下载的话就可以支持远程资源的更新了。
但是这样需要定制引擎
```
```json
{
    "CocosEngine": "3.8.7",
    //...
    "assets": {
        "server": "http://10.2.98.84:8000/",
        "remoteBundles": [
            "common_bundle",
            "test_bundle"
        ],
        "subpackages": [],
        "preloadBundles": [
            {
                "bundle": "main"
            }
        ],
        "bundleVers": {
            "common_bundle": "2c273",
            "internal": "9f19d",
            "main": "1e91a",
            "test_bundle": "7ffc2"
        },
        "preloadAssets": [],
        "projectBundles": [
            "internal",
            "main",
            "common_bundle",
            "test_bundle"
        ],
        "downloadMaxConcurrency": 15
    },
    //...
}
```

JS代码更新|远程包资源更新
:-|:-:
不支持|定制引擎可以支持


[原生平台热更](https://forum.cocos.org/t/topic/148106/46)  
__原生平台支持更新JS,但是因为文件结构只有一套,  
所以只能以热更新的形式,而无法做类似arena那种下载后的包既有代码又有资源的情况,除非同时维护两个项目__
